# 高中生物工具

一个纯本地的命令行小工具，**不联网、不装第三方库、双击即用**。

![遗传杂交预测](docs/截图_杂交.png)

## 五个功能

**1. 细胞结构查询** —— 输入 `线粒体`、`细胞膜` 这类结构名，查分布和功能，覆盖人教版必修一重点细胞器。输入「列表」看全部收录，也支持按功能关键词模糊搜索。

**2. 遗传杂交预测** —— 输入亲本基因型，直接出棋盘格和比例。

```
输入：AaBb x AaBb
输出：后代表现型（比例）: A_B_ : A_bb : aaB_ : aabb = 9 : 3 : 3 : 1
```

支持单基因（`Aa x aa`）和双基因（`AaBb x AaBb`），给出完整棋盘格、基因型比例、表现型比例。

**3. DNA 转录与翻译** —— 输入 DNA 编码链，给出互补链、转录出的 mRNA，以及按密码子翻译的氨基酸序列，附常见密码子表。

**4. ABO 血型遗传** —— 输入父母血型，算出孩子可能和不可能出现的血型，并列出父母可能的基因型。

**5. 同位素查询** —— 24 种常见元素的质量数、天然丰度、稳定性、半衰期、主要用途。生物题常考的 ¹⁴C 测年、¹⁵N 标记、³²P 标记都能查到，每条数据单独标注把握度。

## 使用方法

**方式一：直接跑 exe（Windows，免装 Python）**

到页面右侧的 Releases 下载 `生物工具.exe`，双击运行。

> 注：exe 由 PyInstaller 打包、没有数字签名，部分杀毒软件可能误报。这是打包工具的常见现象。

**方式二：用 Python 跑源码**

```bash
python 生物工具.py
```

Python 3.6 以上即可，只用标准库。Windows / macOS / Linux 都能跑。更详细的操作说明见 [使用说明.md](使用说明.md)。

## 操作

菜单里输入数字选功能，输入 `q` 返回上一层，`0` 退出。

## 数据来源

- 相对原子质量、同位素丰度：IUPAC CIAAW
- 半衰期、衰变方式：NNDC（美国国家核数据中心）、IAEA
- 细胞结构与密码子：人教版教材

同位素数据里把握不足的都标了「中」或「不确定」，请以权威数据库为准。
